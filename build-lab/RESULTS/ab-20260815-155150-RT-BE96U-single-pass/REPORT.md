## Harness defects this session exposed

2. **The warm-up was designed to be discarded.** It turned out to be the most

   5-file delta is the build's own irreproducibility. It is now reported as the
   noise floor rather than thrown away.
3. **Differing files could not be inspected after the fact**, because each build
   overwrites the staged fs. The digest script now archives small differing
   files and ELF fingerprints before they are lost.
