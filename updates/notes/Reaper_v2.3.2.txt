Reaper v2.3.2

A safer firmware-flash screen, Hardware QoS that finally classifies the way
its labels say, and a small security and reliability sweep.

FIRMWARE PAGE
- The flashing overlay can no longer trap you. It now shows a Close button
  (and accepts Esc) on any finished state, and after 25 seconds on any
  long-running one, with a live elapsed-time/phase heartbeat so a stalled
  operation looks different from a working one. Dismissing only clears the
  overlay - it cannot stop a flash already running on the router.
- A good image is no longer wrongly reported "rejected" while the router is
  still verifying it (the wait window was widened).

HARDWARE QoS (CLASSFUL MODE)
- Unmatched traffic now lands in the class actually named "Default" instead
  of sharing the bulk "Downloads" queue.
- The DSCP-to-class map was inverted (gaming and streaming codepoints were
  swapped) - corrected, so traffic reaches the queue named for it.
- Committed minimum rates are now budgeted: a template that asked for 100% of
  the line left unclassified and LAN traffic no guarantee; anything over 85%
  is now scaled down proportionally, preserving your ratios.
- QoS with both bandwidth fields blank now behaves as QoS-off instead of
  reclassifying everything with no shaper.
- The downstream DSCP-to-WMM stamp is now opt-in (it was promoting ordinary
  web browsing to the Voice class on the air).

SECURITY & RELIABILITY
- The QoS diagnostic now reads the shaper the running engine actually uses,
  instead of always reporting a classless box as uncapped.
- Closed a shell-injection path in a VPN-provider setup value.
- The admin password check is now constant-time.
- The health watchdog no longer writes repeated incident dumps to flash under
  a flapping condition.

This is the first release published through the public clean-room CI pipeline.
