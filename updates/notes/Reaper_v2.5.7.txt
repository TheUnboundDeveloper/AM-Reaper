Reaper v2.5.7

Built on RT-BE96U and verified in the image. A focused batch that closes the remaining low-severity findings from the 2026-07-31 security audit; no user-visible behaviour change beyond the password-change form. Not yet cut as a public CI release. The audit remainder now stands at zero Critical and zero High.

> Hardened: five low-severity audit findings closed; the rest verified already-fixed or deliberate

A three-byte over-read in the file-upload boundary scanner is now bounds-checked. The Gatekeeper "grandfather the currently-connected devices" step now refuses to overwrite its authorised-device list if that list is ever too large to load into its buffer — rather than silently dropping the devices it couldn't read — and logs it instead. The AI-Advisor USB-key session file now strips stray line breaks out of a volume name before writing it. The USB-eject helper now accepts only a numeric port or "all". And the password-change request now travels as a POST body instead of defaulting to a URL query, so a changed password no longer lands in browser history, the server access log, or a Referer header. A re-verification pass over the whole audit remainder found several other items were already fixed in earlier releases, and left two open on purpose — most notably the access-restriction rule, which fails open when it has no valid rules because failing closed would lock the administrator out of the router.
