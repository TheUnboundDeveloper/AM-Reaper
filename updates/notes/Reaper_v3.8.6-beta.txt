Reaper v3.8.6 - BETA (Dev branch)

A beta release from the Dev branch: it has had less testing than a
stable release. The previous firmware stays in the standby partition.

Everything in v3.8.5 is included. Both lines carry the same changes: RT-BE96U, RT-BE86U, RT-BE88U and GT-BE98 Pro on

3006.102.10; GT-BE98, GT-BE19000, BQ16 and BQ16 Pro on 3006.102.8.

> Guest portal look restored

The Network page asked for a portal's saved look by the wrong name, showed the

built-in look instead, and a save then wrote that over the stored background, title and terms. The saved look loads

again and a save keeps it; a look that was already overwritten by a save in v3.8.5 has to be set again. The editor

and the wizard show a live phone preview of the portal page.

> Add-on pages

Pages add-ons install (Skynet, scMerlin, YazDHCP's DHCP page and others) showed the stock banner,

menu and tabs inside the Reaper frame. They now get a sheet that hides those, uses the full width and the Reaper

colours. Nine removed page values add-ons still read (cpu_core_num, usb_is_exist, get_label_mac and six lists)

print an empty value instead of nothing, with one log line per value per boot.

> Network page

The Wi-Fi key, RADIUS secret and portal passcode are masked, with Show / Hide. The MAC filter

lists each device as Name (MAC) and offers the wireless devices online to pick from. Cards name the kind of

network and show Secured / Open. Final restyle.

> Device pictures and types are back

Devices: an icon per device, and a dialog to upload or remove a picture

(PNG, JPEG or WebP) and to pick the device type. Pictures set on stock firmware show as they are. The same icons

are on the dashboard and AiMesh client lists. The old picture upload addresses are closed.

> AiMesh page

Final restyle. The backhaul card shows Maximum, the rate the link has negotiated (the Ethernet

port speed, or the Wi-Fi link rate each way), and Current / Average / Maximum are each on their own line.

> Dialogs fit the screen

A dialog taller than the window no longer hangs off it with its buttons out of reach:

it stays in place and the page scrollbar or mouse wheel reaches the rest. No dialog has a scrollbar of its own

except a long MAC filter list. The Devices picture dialog uses the window width.

> Quieter page frame

The band around a page's sections is neutral with a thin accent line, on every page.

> ASUS Router app: opt-in

Administration > System > Login and access > Allow the app (home network only),

off by default. With it on, a request from the app on the main network skips the cross-site, Referer, page-token

and POST-only checks; signing in is still required, and it never applies from the internet, a guest network or a

VPN client. Any device on the main network can claim to be the app. Reaper does not test or support the app and

parts of it do not work. The switch is in the full backup only and is watched by the Security Review.

> Wireless Log:

a Rx / Tx retries column.

> Guide:

the sections for the pages above are updated.
